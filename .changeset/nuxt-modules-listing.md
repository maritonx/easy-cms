Ready for the Nuxt modules list:

- `@easy-cms/nuxt` and `@easy-cms/next` describe Easy CMS as the code-first CMS and app backend that runs inside your app (no longer "headless CMS").
- When a Nuxt app has the module but no `easy-cms.config.ts` (as after `nuxi module add easy-cms`, which installs only the module), the warning lists the packages to install, a short config to start from and the `EASY_CMS_SECRET` to set.
