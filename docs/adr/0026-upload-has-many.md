# ADR-0026: upload หลายไฟล์ (`hasMany`) และการจำกัดชนิดไฟล์

- **สถานะ:** Accepted
- **วันที่:** 2026-10-03

## บริบท

ผู้ใช้ต้องการใส่รูปหลายรูปในบทความ เช่น แกลเลอรี ทางที่มีอยู่คือ `array` ที่มี `upload` อยู่ข้างใน ซึ่งต้องเพิ่มแถว
แล้วเลือกรูปทีละรูป ส่วน `upload` เลือกได้ไฟล์เดียว และไม่มีวิธีจำกัดชนิดไฟล์ (รูปปกเลือก PDF ได้)

## การตัดสินใจ

- **`upload` รองรับ `hasMany`** แบบเดียวกับ relationship โดยเก็บในตารางลูก `<collection>__<field>` (`_order`, `value`)
  - populate, query (`in`), การแยกตามภาษา (`_locale`), type ที่อนุมาน, `generate:types`, schema ของ MCP และการ copy
    ใช้กลไกเดิมของ hasMany เพิ่ม `isHasMany()` ใน core เพื่อให้ทุกจุดตรวจเงื่อนไขเดียวกัน
- **`minRows` / `maxRows`** ใช้ได้กับ upload และ relationship แบบ hasMany (ชื่อเดียวกับ array) ใช้ได้เฉพาะเมื่อมี `hasMany`
  - การตรวจค่าว่างเปลี่ยนไป: รายการว่างถือว่าน้อยกว่า `minRows` ด้วย ใช้กับ array และ blocks เช่นกัน
    ก่อนหน้านี้ระบบข้ามการตรวจเมื่อรายการว่าง ส่วน draft ยังข้ามการตรวจนี้ได้เหมือนการตรวจ `required`
- **`mimeTypes`** (เช่น `['image/*']`) ใช้กับ upload ทั้งแบบไฟล์เดียวและหลายไฟล์
  - ตรวจฝั่ง server ตอนตรวจ reference (อ่าน `mimeType` ของ media ที่ดึงมาอยู่แล้ว ไม่ต้อง query เพิ่ม)
  - ข้อความ error เป็น "must be an image (…)" เมื่ออนุญาตเฉพาะรูป
  - admin กรองตัวเลือกใน MediaPicker และกำหนด `accept` ของช่องอัปโหลด
- **คำบรรยายของแต่ละรูป** ใช้ alt ของ media ถ้าต้องการคำบรรยายเฉพาะหน้า ให้ใช้ array (มีอธิบายไว้ใน recipe "Image galleries")
- **admin:** `UploadManyField`
  - แสดงรูปย่อเป็นตาราง
  - ลากวางเพื่อเรียงลำดับ และมีปุ่ม ← → สำหรับคีย์บอร์ดและ screen reader
  - ลากหลายไฟล์มาวางเพื่ออัปโหลดได้
  - MediaPicker แบบเลือกหลายรูป (`aria-pressed` แล้วกด "Add N") เคารพจำนวนที่เหลือตาม `maxRows`
  - MediaPicker อยู่นอก group ของ field เพื่อไม่ให้ช่องอัปโหลดของ picker ถูกนับเป็นของแกลเลอรี

## ผลที่ตามมา

- ✅ แกลเลอรีใช้งานง่ายเหมือน CMS อื่น และทุก adapter, ฐานข้อมูล และภาษาทำงานเหมือนกัน
- ✅ รูปปกและไฟล์อื่นจำกัดชนิดได้
- ⚠️ config ที่มี `minRows` ใน array หรือ blocks และบันทึกค่าว่างแบบ published จะได้ error แทนที่จะผ่าน
- ❌ ยังไม่มีคำบรรยายต่อรูปใน field เดียว (ต้องใช้ array)
