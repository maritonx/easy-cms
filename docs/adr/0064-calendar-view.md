# ADR-0064: ปฏิทินในหน้ารายการด้วย `admin.calendar` และ FullCalendar 6

- **สถานะ:** Accepted
- **วันที่:** 2026-10-30

## บริบท

- ทีมเนื้อหาต้องเห็นเอกสารตามวันที่ เช่น กิจกรรม หรือโพสต์ตามวันเผยแพร่ และต้องเห็นสิ่งที่ตั้งเวลาเผยแพร่ไว้ทั้งเว็บ ([#272](https://github.com/maritonx/easy-cms/issues/272))
- หน้ารายการมีตัวกรองหลายเงื่อนไขแล้ว ([#88](https://github.com/maritonx/easy-cms/issues/88)) และแอดมินแสดงเวลาตาม `config.timeZone` แล้ว ([#271](https://github.com/maritonx/easy-cms/issues/271))
- REST API ให้ไม่เกิน 100 รายการต่อ request
- รายละเอียดที่ตัดสินใจไว้ทั้งหมดอยู่ใน #272 (grilling 2026-10-30) ADR นี้บันทึกส่วนที่เป็นโครงสร้าง

## การตัดสินใจ

- **ประกาศใน config ไม่เดาจาก field:**
  - `admin.calendar: { start, end?, color? }` ของ collection
  - `start`/`end` เป็น field วันที่ระดับบนสุด
  - `color` เป็น select หรือ relationship ที่ไม่ใช่ hasMany
  - collection ที่ไม่ได้ประกาศไม่มีโหมดปฏิทิน
- **โหมดหนึ่งของหน้ารายการ ไม่ใช่หน้าใหม่:**
  - `?calendar=month|week|day|agenda&date=YYYY-MM-DD` อยู่ใน URL เปิดลิงก์แล้วเห็นแบบเดียวกัน
  - ใช้ตัวกรอง คำค้น และสิทธิ์อ่านเดียวกับรายการ
  - หน้ารายการไม่โหลดตารางระหว่างอยู่ในโหมดนี้
- **ข้อมูลผ่าน REST API เดิม:**
  - ช่วงวันที่เป็น `where` (เริ่มก่อนจบช่วง และจบหรือเริ่มในช่วง) รวมกับตัวกรองของรายการ
  - โหลดหน้าละ 100 สูงสุด 5 หน้า (500 รายการ) ถ้าเกินบอกให้กรองเพิ่ม
  - ไม่เพิ่ม endpoint
- **FullCalendar 6 (MIT: core, daygrid, timegrid, list, interaction)** โหลดเฉพาะตอนเปิดโหมดปฏิทิน (`defineAsyncComponent`):
  - ทดลองแล้วผ่านเรื่องภาษาไทย (พ.ศ. ชื่อเดือนไทย) การลาก และคีย์บอร์ดขั้นพื้นฐาน
  - ชื่อสำหรับโปรแกรมอ่านหน้าจอใส่เองผ่าน `dayCellDidMount` และ `eventDidMount` เพราะตัวเลือก hint ของไลบรารีกลายเป็น `title`
  - FullCalendar 7 เปลี่ยนโครงสร้างเป็น `@full-ui/headless-calendar` และต้องใช้ `temporal-polyfill` จึงยังไม่ใช้
- **เขตเวลาไม่ใช้ plugin:** ให้ FullCalendar ทำงานใน `UTC` แล้วส่งเวลาตามนาฬิกาของ `config.timeZone` เข้าไป (`toZoned`) และแปลงกลับตอนรับค่า (`fromZoned`) แบบเดียวกับช่องกรอกวันที่ใน #271
- **วันทั้งวัน:** เริ่มเที่ยงคืนตามเขตเวลา และไม่มีวันจบหรือจบเที่ยงคืน ถือว่าเป็นทั้งวัน ไม่เพิ่ม field `allDay`
- **สร้างจากช่องว่าง:** เปิด drawer เอกสารใหม่พร้อมวันที่ ถ้า collection มี drafts จะถูกสร้างเป็นฉบับร่าง
- **สี:** 8 สีตามลำดับ option ของ select หรือ hash ของ id ของ relationship

## ผลที่ตามมา

- ✅ ไม่มี endpoint หรือ migration ใหม่ ปฏิทินได้ตัวกรองและสิทธิ์ของรายการทันที
- ✅ admin ที่ไม่ได้เปิดโหมดปฏิทินไม่ต้องโหลด FullCalendar
- ⚠️ ช่วงที่มีเกิน 500 รายการแสดงไม่ครบ ต้องกรอง
- ⚠️ ลากในปฏิทินด้วยคีย์บอร์ดไม่ได้ ต้องมีปุ่ม "ย้ายไปวันที่…" (PR ถัดไปของ #272)
- ⚠️ การเลือกช่องว่างเพื่อสร้างใช้คีย์บอร์ดไม่ได้ ปุ่ม "สร้างใหม่" ของหน้ารายการยังใช้ได้ แต่ต้องกรอกวันที่เอง
