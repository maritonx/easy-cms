# ADR-0027: ลืมรหัสผ่านและคำเชิญทางอีเมล

- **สถานะ:** Accepted
- **วันที่:** 2026-10-03

## บริบท

ผู้ใช้ที่ลืมรหัสผ่านต้องให้ admin ตั้งรหัสให้ใหม่ และ admin ที่เพิ่มผู้ใช้ต้องตั้งรหัสแล้วบอกกันเอง
ระบบอีเมลมีอยู่แล้วตั้งแต่ 0.20 (ADR-0023)

## การตัดสินใจ

- **ลิงก์ทางอีเมล** ไปยัง `<admin>/reset-password?token=…` ซึ่งเป็นหน้าเดียวที่ใช้ทั้งลืมรหัสผ่านและคำเชิญ
- **token ไม่ได้เก็บใน DB:** `<payload>.<HMAC>`
  - payload คือ `{u, p, e}` (user id, purpose reset|invite, เวลาหมดอายุ)
  - ลายเซ็นครอบ fingerprint ของ password hash ปัจจุบัน (sha256) พอรหัสเปลี่ยน ลิงก์จึงใช้ไม่ได้อีก ได้ผลเหมือนใช้ได้ครั้งเดียว
  - ไม่ต้องมีตารางใหม่หรือ migration
  - อายุลิงก์: reset 1 ชั่วโมง, คำเชิญ 7 วัน (ตั้งค่าได้)
  - ข้อควรรู้: ข้อความอีเมลรวมถึงลิงก์ถูกเก็บในคิว `email-deliveries` ระหว่างรอส่ง
- **ไม่บอกว่าอีเมลมีบัญชีหรือไม่:** `forgot-password` ตอบเหมือนกันทุกกรณี
  - จำกัด 3 คำขอต่ออีเมลและ IP ต่อ `lockWindow` ใช้ตาราง `login-attempts` ที่มีอยู่ ที่เกินจะถูกเพิกเฉยเงียบๆ
  - token ที่ผิดนับเป็นความพยายามที่ล้มเหลวต่อ IP
- **ลิงก์ชี้ไปที่ `serverURL` เท่านั้น** บน production เพราะ Host ของ request ปลอมได้ (password reset poisoning)
  - ตอนพัฒนาใช้ origin ของ request
  - ถ้าไม่มี `email` หรือไม่มีที่อยู่ที่เชื่อถือได้ หน้า admin จะไม่แสดงลิงก์และปุ่มเหล่านี้ (`/users/init.passwordReset`, `AdminSchema.passwordLinks`)
- **หลังตั้งรหัส:**
  - ยกเลิก session ทุกเครื่อง (ใช้การ update รหัสผ่านของ Local API)
  - login ให้ในเบราว์เซอร์นั้น
  - ถ้าเป็นการ reset ส่งอีเมลแจ้งว่า "รหัสผ่านถูกเปลี่ยน"
- **คำเชิญ:**
  - สร้างผู้ใช้โดยไม่มีรหัสผ่านได้แล้ว บัญชีนั้น login ไม่ได้จนกว่าจะตั้งรหัสจากลิงก์
  - admin ที่เว้นรหัสว่างตอนสร้างจะส่งคำเชิญให้อัตโนมัติ
  - หน้าผู้ใช้มีปุ่ม "ส่งลิงก์ตั้งรหัสผ่าน" (`POST /users/:id/password-link` เฉพาะ admin ที่ login ด้วย session ไม่รับ API key)
- **ข้อความอีเมล:**
  - ค่าเริ่มต้นเป็นไทยหรืออังกฤษ ตามภาษาของหน้า admin ที่ส่งมากับคำขอ ไม่อย่างนั้นใช้ `admin.locale`
  - ปรับเองได้ด้วย `auth.emails.{resetPassword, invite, passwordChanged}`

## ผลที่ตามมา

- ✅ ผู้ใช้กู้บัญชีเองได้ และ admin ไม่ต้องรู้รหัสของคนอื่น
- ✅ ไม่เพิ่มตารางหรือ migration
- ⚠️ `cms.create('users')` ไม่บังคับใส่ `password` แล้ว (type ก็เปลี่ยนตาม)
- ❌ ยกเลิกลิงก์รายตัวไม่ได้ (ยกเลิกได้ด้วยการเปลี่ยนรหัสผ่าน หรือปิดบัญชี)
- ❌ ยังไม่มีการ login ผ่านระบบภายนอก (`auth.strategy`)
