# ADR-0062: rate limit ของ API นับในหน่วยความจำ แล้วรวมกันผ่านฐานข้อมูล

- **สถานะ:** Accepted
- **วันที่:** 2026-10-29

## บริบท

- ก่อนหน้านี้ ([#168](https://github.com/maritonx/easy-cms/issues/168)) มีการจำกัดแค่ login, การสมัครสมาชิก และฟอร์มสาธารณะ ซึ่งทั้งหมดนับแถวในตารางทุกครั้ง ส่วน REST API ทั่วไปไม่มีการจำกัด และ `SECURITY.md` ให้ไปตั้งตัวจำกัดไว้ข้างหน้าเอง
- issue ต้องการให้ตั้งค่าเกณฑ์ต่อ IP และต่อ API key ได้ เก็บในฐานข้อมูลเพื่อใช้ข้ามหลาย instance ได้ และตอบ `429` พร้อม `Retry-After`
- การเขียนฐานข้อมูลทุก request (รวม GET) ทำให้การอ่านช้าลง โดยเฉพาะบน SQLite ที่เขียนได้ทีละรายการ

## การตัดสินใจ

- **`rateLimit` ค่าเริ่มต้นปิด:** `{}` ใช้ค่าเริ่มต้น และเทมเพลตของ `create-easy-cms` กับ `next-starter` เปิดไว้ เปิดเองใน minor ไม่ได้ เพราะ build แบบ static หรือระบบที่อยู่หลัง proxy แต่ไม่ได้ตั้ง `trustProxy` จะโดนตัดทันทีหลังอัปเกรด
- **ใครถูกนับ:**
  - ผู้ไม่ได้ login นับต่อ IP (300/นาที)
  - ผู้ใช้ที่ login นับต่อผู้ใช้ (1,200)
  - API key นับต่อ key (1,200)
  - ไม่นับ health check และ `jobs/run`
  - ใช้กับทุก request ที่ผ่าน REST handler แต่ไม่รวม Local API
- **ช่วงเวลาคงที่ 60 วินาที** ตัวนับเดียวสำหรับทั้งการอ่านและการเขียน
- **นับในหน่วยความจำ แล้วรวมกันทุก 5 วินาที:**
  - แต่ละ instance เพิ่มยอดที่นับได้เข้าแถว `rate-limits` ต่อ key และช่วงเวลา (`increment`) แล้วอ่านยอดรวมกลับมา การ sync ทำในเบื้องหลัง ไม่มี request ไหนต้องรอฐานข้อมูล
  - ยอดอาจเกินไปได้ เท่ากับจำนวนที่ instance อื่นนับไปในช่วงระหว่าง sync
- **ไม่เก็บ IP:** key ของผู้ไม่ได้ login เป็น HMAC ของ IP ที่สร้างจาก `secret`
- **ไม่รู้ IP:** ไม่จำกัดผู้ไม่ได้ login และ log เตือนครั้งเดียว ถ้านับรวมกันหมด ผู้เข้าชมทุกคนจะโดนตัดพร้อมกัน
- **header:** ส่งแค่ `Retry-After` ตอนตอบ 429 (header `RateLimit` ยังเป็น draft)

## ผลที่ตามมา

- ✅ การอ่านไม่ต้องเขียนฐานข้อมูลเพิ่ม และกันการยิงถล่มได้แม้ไม่มี CDN
- ✅ หลาย instance ใช้ยอดร่วมกัน
- ⚠️ ยอดเป็นค่าประมาณระหว่างการ sync ใช้กันการยิงถล่ม ไม่ใช่การนับที่แม่นยำ (เช่น เพื่อเก็บเงิน)
- ⚠️ ที่ขอบช่วงเวลา client ส่งได้ถึงราว 2 เท่าของเกณฑ์ภายในเวลาสั้นๆ
- ⚠️ การเปิดต้องสร้าง migration สำหรับตาราง `rate-limits`
- ❌ ยังไม่มี header `RateLimit` ให้ client ชะลอเองก่อนโดนตัด
