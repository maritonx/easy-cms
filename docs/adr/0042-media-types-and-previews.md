# ADR-0042: อัปโหลดหลายไฟล์ ชนิดไฟล์ และตัวอย่างในคลังสื่อ

- **สถานะ:** Accepted
- **วันที่:** 2026-10-07

## บริบท

- หน้า Media ลากหลายไฟล์มาวางได้ แต่อัปโหลดจริงแค่ไฟล์แรก: `UploadDropzone` ไม่ได้ส่ง `multiple` มา และ Vue แปลง boolean prop ที่ไม่ได้ส่งเป็น `false` ส่วนที่อัปได้หลายไฟล์ (แกลเลอรี) ก็ส่งทีละไฟล์ต่อกันโดยไม่มีความคืบหน้า
- ตรวจชนิดจากเนื้อหาได้แค่รูป PDF ข้อความ และ mp4 องค์กรอัปเอกสาร Office ไม่ได้
- ไฟล์ที่ไม่ใช่รูปแสดงแค่นามสกุล หน้าแก้ไขแสดงตัวอย่างได้แค่รูป และไฟล์ที่เสิร์ฟเองมี CSP `sandbox` ซึ่งทำให้เบราว์เซอร์ไม่แสดง PDF

## การตัดสินใจ

- **คิวอัปโหลด:** พร้อมกันครั้งละ 3 ไฟล์ด้วย `XMLHttpRequest` (เพราะ `fetch` ไม่บอกความคืบหน้าการส่ง) ยกเลิกได้ด้วย abort ลองใหม่เฉพาะไฟล์ที่ล้ม ตรวจขนาดกับ `maxFileSize` ก่อนส่ง (schema ส่ง `upload.maxFileSize` และ `mimeTypes` มาให้ admin) เมื่อเสร็จทั้งชุดหน้า Media เลือกไฟล์ใหม่ไว้ `multiple` เป็น `true` โดยค่าเริ่มต้น
- **ชนิดไฟล์ใหม่จากเนื้อหา:** Office (zip ที่มี `word/document.xml`, `xl/workbook.xml`, `ppt/presentation.xml` ชื่อ entry ใน zip ไม่ถูกบีบอัด จึงหาได้โดยไม่ต้องแตก zip), OpenDocument (entry `mimetype` แรกตามที่ format บังคับ), zip, MP3, WAV, Ogg, M4A, WebM, MOV CSV แยกจากข้อความด้วยชื่อไฟล์เท่านั้นเพราะเนื้อหาเหมือนกัน Office แบบเก่า (OLE) ไม่รองรับ
- **กลุ่มชนิดไฟล์** `documents`, `office`, `archives` ใช้ได้ใน `upload.mimeTypes` และ `mimeTypes` ของ field (`expandMimeTypes`) admin ได้รายการที่แตกกลุ่มแล้ว ค่าเริ่มต้นยังเป็นรูปและ PDF starter template ตั้ง `['image/*', 'documents']`
- **icon ตามชนิด:** กลุ่ม pdf/word/sheet/slides/archive/audio/video/text/file ใช้ icon ของ Lucide และสีจากตัวแปร CSS `--kind-*` ที่ตั้งแยกธีมสว่างและมืด พร้อมป้ายนามสกุล
- **ตัวอย่างตามชนิด:** วิดีโอและเสียงใช้ตัวเล่นของเบราว์เซอร์ (เพิ่ม `media-src 'self' blob: https:` ใน CSP ของ admin เพราะไฟล์อาจอยู่บน CDN) PDF ใช้ตัวอ่านของเบราว์เซอร์ใน iframe ผ่าน route ของ API ซึ่งตอนนี้เสิร์ฟ PDF โดยไม่มี CSP `sandbox` (ตัวอ่าน PDF ของเบราว์เซอร์ทำงานแยกจาก origin ของเว็บ ไฟล์ชนิดอื่นยังมี sandbox เหมือนเดิม) ข้อความและ CSV อ่าน 64 KB แรกผ่าน API แสดงไม่เกิน 100 บรรทัด ถอดรหัสตาม BOM แล้ว UTF-8 แล้ว Windows-874 Office และ zip แสดง icon กับปุ่มดาวน์โหลด ไม่ส่งไฟล์ไปบริการภายนอก
- **มุมมองกริด** เป็นค่าเริ่มต้นของ Media สลับเป็นตารางได้และจำไว้ในเครื่อง การ์ดเลือก ลากไปโฟลเดอร์ และย้ายได้เหมือนตาราง

## ผลที่ตามมา

- ✅ อัปเอกสารและสื่อหลายชนิดได้ทีละหลายไฟล์ เห็นความคืบหน้าและไฟล์ที่ล้ม
- ✅ ดูไฟล์ได้ในหน้าโดยไม่ต้องดาวน์โหลด และไม่มีไฟล์ออกไปนอกระบบ
- ⚠️ PDF ที่เสิร์ฟเองไม่มี CSP sandbox อีกต่อไป (พึ่งการแยกของตัวอ่าน PDF ในเบราว์เซอร์)
- ❌ ยังไม่รองรับ Office แบบเก่า การลากโฟลเดอร์จากเครื่อง และการอัปโหลดตรงไป storage สำหรับไฟล์ใหญ่ (Vercel จำกัดราว 4.5 MB ต่อ request)
