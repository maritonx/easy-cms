# Easy CMS 1.0.0

**Easy CMS 1.0** is out: the first version meant for production use. It is the embedded,
code-first headless CMS for Next.js and Nuxt (or on its own server): your content model is
TypeScript in your repository, and the admin, a typed Local API and REST come with your app, on
one deployment and your own database.

## Get it

```bash
# A new project, or add it to a Next.js or Nuxt one
npm create easy-cms@latest

# Upgrading from 0.x: back up, then every package together
npm install @easy-cms/core@latest easy-cms@latest  # and your adapter, plugins…
npx easy-cms migrate
```

Upgrading from 0.x: follow [From 0.x to 1.0](https://easy-cms-website.vercel.app/docs/upgrading#to-1-0).
Most apps only change their config; the app names each renamed option when it starts.

## What 1.0 promises

- **Breaking changes only in a major release** (2.0), each with an upgrade guide. Minor releases
  add features; patch releases fix bugs.
- **Covered:** the config, the Local API, REST routes and error codes, the CLI, adapters, and your
  data: upgrades migrate it forward, and CI upgrades databases made by releases back to 0.10 on
  every commit.
- **Renamed APIs keep working** until the next major, with a deprecation warning.
- **Support:** 0.x is no longer supported. Security fixes go to the latest 1.x minor; when 2.0
  comes out, 1.x gets security fixes for six more months.
- **Experimental:** `@easy-cms/plugin-ecommerce`, `@easy-cms/plugin-graphql` and
  `@easy-cms/plugin-mcp` may still change in a minor release until they are declared stable.

Details: [Versions and deprecations](https://easy-cms-website.vercel.app/docs/versioning).

## How it got here

The road to 1.0 ([roadmap](https://github.com/maritonx/easy-cms/blob/main/docs/ROADMAP.md)) added
no features. It settled the API (0.60), went through a self-review against OWASP ASVS level 1
and fixed what it found (0.62–0.66, with published advisories), tested the experimental plugins
against real services and clients (Stripe, urql with codegen, Claude), and checked Getting
started word for word on a clean Ubuntu 26.04 with npm, pnpm, Yarn and Bun.
